# scars-web

Minimal, premium single-page showcase website for the [GitScars (`git-scars`)](https://github.com/Pavanspoojary/scars) open-source project.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Lucide React (Clean inline SVGs, zero emojis)

## Quickstart

```bash
# Install dependencies
pnpm install

# Start local development server
pnpm run dev

# Build production static bundle
pnpm run build

# Preview production build locally
pnpm run preview
```
